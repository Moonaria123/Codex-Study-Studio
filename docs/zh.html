05 / 开始你的学习工作室

选择适合你的安装方式。

中英文技能包均完整独立，可安装一个，也可同时安装。附带的学习网页界面初始为英文。

01

让 Codex 安装

使用 $skill-installer 安装这个技能：
https://github.com/Moonaria123/Codex-Study-Studio/tree/main/skills/study-studio-zh
02

下载 ZIP

将技能文件夹解压到 ~/.codex/skills/ 或 %USERPROFILE%\.codex\skills\，保留含 SKILL.md 的完整文件夹。

英文技能包 ↓中文技能包 ↓
03

克隆后安装

git clone https://github.com/Moonaria123/Codex-Study-Studio.git
cd Codex-Study-Studio
python scripts/install.py --language zh
04

内置安装脚本

python3 "$CODEX_HOME/skills/.system/skill-installer/scripts/install-skill-from-github.py"   --repo Moonaria123/Codex-Study-Studio   --path skills/study-studio-zh

先设置 CODEX_HOME，或使用完整指南中的默认目录命令。
