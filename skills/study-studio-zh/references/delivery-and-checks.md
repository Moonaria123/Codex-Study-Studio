# 交付与有意义的验证

内容核验的唯一知识基准是目标书籍；官方材料仅核验考纲和考试形式。抽查每个重要解释、案例规则、公式、术语及知识关联是否能回到原书定位，删除无依据的延伸。另检查学习材料内没有保护性声明；制作缺口只留在验证记录及交付沟通中，不能混入教学正文。

## 本地和网盘

先核实阅读根目录和章节父目录。为新产物写入暂存版本，验证通过后再发布；已有目标先保存可恢复旧版，不进行无关清理。网盘连接器足够时优先连接器；不支持所需动作再用合规的本地同步或UI方案，并说明差异。

上传后读取新文件元数据，确认文件名、大小、MIME与父目录；移动旧版本时只移除已核实的旧父目录，保留其他父目录。完成后对照操作前的清单验证目标集合，未参与更新的产物不改变。保留交付清单（路径/ID、版本、大小或哈希、验证、原位置）。保留统一网页稳定的文件ID和可行的本地文件路径；更新前提示可导出学习备份，不自动清除浏览器数据。

对用户的一次制作请求，不自动公开分享文件或创建外网部署。在线语音/视频需要的费用、凭据、发送内容范围按当前授权核对；已有授权不反复询问，也不将旧课程授权无限延伸。

## 验证证据

| 对象 | 最小有意义检查 |
|---|---|
| 章节拆分 | 页数、起止页视觉确认、全部原页映射、原文件未改变 |
| Outline/Syllabus | 章节清单完整；Outline知识仅来自原书；Syllabus仅含已核实官方学习/考试要求；未读或未核实范围在制作记录中登记 |
| CharpterReview | 各节覆盖；定义/公式/数值/辨析/关联逐项对照原书；无外部补充或过度解读；核心知识到模块的映射 |
| PPT/脚本 | 实际渲染抽查首尾、密集页、公式与例题页；脚本逐页匹配；术语、引用准确 |
| 视频 | 实测每段/总时长、音轨和画面完整；开头/中部/末尾试听；字幕对齐/无越界；思考时间有效 |
| 概览图/PDF | 实际查看导出图；缩放后文本可读；没有重叠、裁切或错字；长题分页不中断含义 |
| 交互网页 | 实际浏览器点击入口/章节/回答；跨刷新恢复；保存、放弃和取消退出分别生效；导图视图复原；图像导出 |
| 历史/错题 | 快照冻结原题与答案；正确分值及时间；同一次多次保存不增加错题次数；独立第二次作答可累计；打印PDF内容完整 |
| 备份 | 有真实进度/记录/地图状态后导出→新浏览器存储导入→恢复一致；无效/异课程/恶意文件不执行代码且不改变当前数据 |
| 章节扩展 | 新章入口可用；旧章ID和记录仍可恢复；更新答案不改写过去记录 |

运行时间统计暂停于非学习界面或隐藏页面。考试计时规则另行明确，不能无意把学习计时假作官方规则；用缩短时间或已到期状态验证自动交卷与退出弹窗的竞争情形。练习模式与考试模式的答案显示时点需要单独检查。

首个复杂网页或涉及数据恢复的修改，宜由独立检查者审查输入校验和历史保护，并以实际浏览器验证；审查报告不能替代运行。只在新增变更或失败处扩大测试，不反复运行无关全套。测试使用合成内容/隔离浏览器，不能清空用户真实记录。

## 版本恢复

完整 JSON 备份包含课程身份和schema版本、导图状态、未完成进度、历史快照、由其构成的错题数据、用户闪卡编辑与设置。导入前验证结构/大小/课程兼容性，确认替换或合并规则，失败保持当前数据不变。知识内容随HTML提供，学习记录备份不是教材副本替代品。

浏览器本地数据不会因上传网盘而同步到其他设备；文件路径、浏览器配置或存储策略改变可能导致新存储区域。备份导入必须能恢复之前导出的同课程数据。若提供独立HTML历史报告，将其明确标为附加浏览/分享快照；它不是完整学习备份。

旧的分章网页若已有学习记录，不可默认假设可以读取或自动迁移：检查实际旧格式与可导出能力，支持时提供明确转换，不能支持时保留旧文件并说明。归档不等于删除。
