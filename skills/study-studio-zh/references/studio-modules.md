# Studio 模块制作

本次请求包含章节教学材料、视频、知识概览图或可打印练习时，读取本参考文件。以 `CharpterReview.md` 和相应原书章节为内容依据；`Syllabus.md` 用于确定考核成果的优先级，不得补写原书没有覆盖的知识。

指定版本原书是唯一知识来源和最终事实标准。章节评述是可追溯的衍生文档，不是独立来源。沿用旧内容前须回原书核对。不得用网络事实、其他教材、模型知识、额外理论或推测解释扩充内容。官方资料只控制考试形式与学习要求元数据。原因、条件和关系的解释不得超出原书依据。原创案例和问题可以更换数值或假设条件来应用书中规则，但不得加入无依据的现实事实。

## 共同教学约定

各模块围绕原书小节顺序与知识关系组织。先讲知识，再用案例辅助解释；案例不能成为代替知识讲解的主线。

对每个有实质内容的小节：

1. 使用原书术语陈述概念或学习成果。
2. 解释其含义、运作方式与重要性。
3. 区分关联或易混概念，给出判断区别的规则。
4. 有助于理解时，演示简短具体的案例、计算、图示或反例。
5. 官方考纲或证据支持时，指出考试提示、常见错误或限制。
6. 用简短问题及答案／解释检验理解。

在知识讲解后，以较完整的例题作为章节收尾。视频揭示答案前留思考时间。展示公式、代入、单位、推理和结果解释，不能只给答案。

在课件、备注、评述和试题中加入来源页码，使用不抢眼的脚注或元数据。不要反复口述页码或介绍原书的组织方式。任何学习材料均不加入“仅供参考”“不保证”“请自行核实”等保护性文字。真实的提取缺口、工具限制或证据冲突写入制作记录及交付沟通。保留原书自身讲授的条件和边界；它们属于知识，不是免责声明。

明确区分：

- 原书的定义、案例、练习和计算；
- 对原书材料的改编；
- 自编课堂例示和原创题。

不得暗示原创题、章节分配或练习权重属于官方安排。保留官方术语与拼写。缩写首次出现时释义，在评述、课件、讲稿、视频、概览图和练习中统一用词。

沿用课程既定语言或用户明确选择。未指定语言的新普通书籍默认采用原书主要语言，保留官方考试术语。课件、讲解和字幕采用用户要求的语言；不得擅自翻译或将明确指定单一语言的课程改为双语。附带网页的英文界面不决定教学内容语言。

## 教学课件

每章制作一份可编辑课件。从结构化幻灯片清单生成，不把 PPT 文件当作唯一事实来源。每页使用稳定 ID，至少记录：

- 视频部分和小节；
- 页面类型：教学、辨析、例题、小测、答案、回顾或收尾练习；
- 标题与可见内容；
- `CharpterReview.md` 中的知识点 ID；
- 来源定位及原创／改编标识；
- 讲稿片段；
- 可选的表格、图示或公式；
- 可选的思考停顿时长。

按以下顺序安排：

1. 章节学习地图与成果；
2. 逐节知识教学；
3. 需要综合关系时给出精炼回顾或比较；
4. 原创或改编收尾练习，问题与答案分开成页。

普通教学页表达一个完整概念或辨析点。屏幕文字便于扫读，详细讲解放在演讲者备注和讲稿中。比较用表格，顺序用流程，有因果或结构关系时用标注清楚的图。图必须表达关系；装饰箭头和无关图库图片不算教学图示。

在统一页脚位置加入简短来源。出处可能误认时，显示 `Author-created question`、`Author-created illustration`、`Adapted from ...` 或含义相同的标识。问题页不显示答案。

### 课件验收

- 每个范围内小节和重要知识点至少映射到一张教学页。
- 定义、公式、表格和术语与原书一致。
- 重要辨析有明确比较，而非顺带提及。
- 知识教学先于收尾练习；例子没有取代知识序列。
- 每张有讲解的页面具备与画面对应的演讲者备注。
- 课件能打开并可编辑；渲染后无裁切、重叠或过小文字。
- 实际查看密集、公式、表格、问题和答案页；短课件逐页查看。

## 讲稿

每章创建一份 Markdown 讲稿，使用稳定幻灯片 ID。各页包括小节／来源定位、知识点、可见内容、必要的出处标识、讲解和停顿指令。

以讲师向学习者讲授的方式写作。解释陈述之间的推理，需要时给出简短例子，说明如何排除容易误选的解释。避免照读要点或只介绍教材有什么。页码放在来源字段，通常不口述。

讲稿与课件从同一幻灯片清单生成，或逐项对齐清单。验证时从清单重构预期讲解并对比讲稿，防止后期改动悄悄导致版本不一致。

收尾练习使用问题页、明确停顿、独立答案页。答案讲解示范可复用方法：识别要求、选择规则或公式、应用、核算、解释情境中的含义。

### 讲稿验收

- 每项可见概念均有教学解释，讲解与画面不冲突。
- 语言自然连贯、术语准确，不反复加入防御性文字或来源索引。
- 案例足够简短，能突出概念，且标识准确。
- 小测和收尾练习均有完整答案与解释。
- 公式讲解说明变量与单位，计算展示中间步骤。
- 自动检查缺失页 ID、未翻译片段、重复出处语句和未解释缩写后，再做语义复核。

## 教学视频

课件和讲稿通过内容检查后才制作视频。渲染最终幻灯片，按讲稿片段合成或录制音频。依据实测音频时长构造视频和字幕时间轴；已有音频时不得按字数估算字幕时间。

建议的可复用流程：

1. 冻结幻灯片清单，逐页渲染为图片。
2. 对各页图片、讲解片段、声音配置和时序输入计算校验值。
3. 仅当所有相关指纹一致时复用缓存音频和单页视频。
4. 逐片段生成音频，使局部发音或措辞可单独修改。
5. 片段之间加入自然间隔，页末短暂停留。
6. 问题或计算后加入明确的静默思考时间，下一页才显示答案。
7. 以实际口述文本和测量的片段边界生成字幕，按请求烧录或附带字幕文件。
8. 拼接已验证片段，输出章节／幻灯片标记及渲染清单。

使用适合用户要求语言与地区的自然清晰声音，不预设口音。须试听专业术语、缩写、符号和数字。信号统计与成功解码不能证明发音合格。

按用户要求、内容密度和自然小节边界决定视频分段与时长，不预设段数或时长，也不要拉长讲解凑时长。

字幕采用指定语言，忠实于讲解，通常最多两行，不遮挡公式或关键内容。优先按句子或分句切分，避免短到无法阅读的闪现。思考停顿期间不得提前显示答案字幕。

### 视频验收

- 所有幻灯片按清单顺序各出现一次，音画完整，字幕同步。
- 从媒体元数据报告实际时长，满足请求范围。
- 思考停顿达到声明时长，答案只在其后开始。
- 每个输出完整解码，有可理解的音频，无意外削波或长时间静默。
- 字幕还原讲解、适合字幕区域并采用指定语言。
- 查看开头、中间、末尾、密集、公式、问题和答案画面，每个视频部分均取样。
- 试听包含术语、数字和转场的片段。存在发音限制时记录，不以自动检查代替主观质量结论。

## 详细知识概览图

每章制作一张原创、高信息密度的概览图。可行时提供可缩放矢量版和便于查看的高清位图。用代码或可编辑设计元素构建文字与几何，不依赖生成式图片中的文字。

概览图应呈现本章概念结构。按主要小节组织，选用少量有目的的视觉形式，例如：

- 分类层级；
- 过程或生命周期流程；
- 易混概念比较矩阵；
- 含变量定义的公式区；
- 驱动因素与结果的因果链；
- 考试提示与易错点标注。

图标只辅助导航，不代替概念。每条连线有明确语义。例子从属于被解释的原理。使用短语，保留原书术语，详细叙述放入 `CharpterReview.md`。

### 概览图验收

- 覆盖主要小节和核心考试辨析。
- 文字可选取或来自已审核内容，拼写正确，目标尺寸下可读。
- 渲染后节点、标签、连线和面板没有裁切或重叠。
- 公式、箭头、分组和图例准确表达关系。
- 常见桌面显示和缩放后均清楚；大型海报可分区截图复查。
- 矢量版与位图版内容相同。

## 可打印练习与参考答案

设计考试风格题目前，研究当前适用的官方考试形式。优先官方考纲、考试规定、样卷和答题指南。记录 URL、发布或查阅日期及各来源实际能证明什么。样卷说明观察到的形式；除非官方明确说明，否则不能证明章节权重。

原创题覆盖本章重要知识、考核成果、辨析、常见混淆、公式和解释能力。按官方证据选择题型，可能包括直接选择、陈述组合、情境组、计算或书面作答。不要仅因为参考项目使用了选择题就固定所有课程使用选择题。

按用户请求和已核实的适用官方形式确定题量、分值和节奏。没有适用官方形式时，按教材覆盖和学习目标设计练习。教学设计须标明其性质，不冒充官方章节蓝图。

各题应包括：

- 稳定 ID、主题、小节和印刷来源页码；
- 如 `Author-created question` 的出处标识；
- 适用时的情境与陈述；
- 有依据时的分值和建议时间；
- 正确答案或评分指引；
- 核心概念解释；
- 计算／推理步骤；
- 有选项时对易误选项的分析；
- 有助于理解的考试提示或易错点。

按重要内容矩阵分配覆盖，不机械平均分题。避免无关细节、歧义、无依据假设和纯语法陷阱。计算须信息充足、单位一致，并有唯一可辩护的结果。

默认 PDF 先给完整试卷，再给清晰分隔的答案部分；用户指定交错答案时遵循用户。包含导航、页码和易读来源。尽可能避免题目不合理跨页；长解析可以连贯分页，不留大面积空页。

### 练习验收

- 每题映射到章节知识点和可获取的官方学习成果。
- 独立内容复核逐一核对答案、计算、分值和来源定位。
- 原创／改编内容标识齐全，无证据时不将练习分配称作官方安排。
- PDF 提取文本与已审核题目源数据一致。
- 渲染并查看每页，检查裁切、孤立标题、不合理分页和过小文字。
- 文件能打开，页数合理，字体正常，题目及答案完整。

## 重建与交付

将已审核内容数据、清单和渲染代码与成品分开。术语、答案、公式或引用变化时，受影响的下游产物必须重新生成或核验。按内容指纹复用不变的幻灯片、音频和视频；缓存命中不能替代语义检查。

替换已有交付前比较文件名、版本和内容校验值。按要求在约定位置保留旧版；只有稳定链接属于约定时才原地更新。上传或移动后读取远端名称、类型、大小和父目录。上传成功不证明内容正确；分别保留本地验证证据和交付回执。
