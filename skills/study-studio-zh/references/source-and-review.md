# 来源、全书理解与章节精读

## 唯一知识源

目标版本书籍是 Outline、CharpterReview 和所有学习模块的唯一知识来源及事实标准。仅允许忠实归纳、必要释义、书中有依据的关系连接和必要算术推演。不得用外部检索、模型常识、其他教材或先前生成内容填补书中空白。案例优先采用书中案例；自编情境只能应用书中规则，假设条件与原创标识简明呈现，不加入真实世界背景事实。

官方资料与此分工明确：只用于 Syllabus 的学习要求、考试形式及其章节映射。它们不能替代原书知识，也不能被用来扩写章节事实。版本冲突或未覆盖要求写入制作记录并向用户报告；不要把冲突说明、自保文字或工具限制插入学习材料。

## 来源登记与页码

在课程 Studio.json 登记 `courseId`、书名/科目、source 文件位置或网盘 ID、版本、校验值、语言、输出位置、章节清单和已完成模块；按需记录官方文档 URL/查阅日期、交付 ID、验证结果。它用于恢复任务与更新同一资源，不记录令牌或登录信息。

每章至少记录 `id`、原书章节号/标题、`locatorType`、源定位范围、拆分后文件路径/ID、精读状态。PDF 使用 `pdf-pages`、原文件一基闭区间 `[start,end]` 和印刷页码字符串；Markdown 可用 `markdown-lines` 和一基行号范围；DOCX/EPUB 使用节标题、段落或锚点。非分页材料不填假页码。印刷页含罗马数字、附录号或重复编号时保留原标签，不假设文件页偏移全书一致。PDF拆分后 `localPage = originalFilePage - start + 1`，引用时明确使用哪一套页码。

PDF 优先使用可提取文本并保留原页码；扫描页先OCR再对照实际页面。图片中定义、表格数值、公式符号、上标/下标、图中关系需视觉复核。目录、PDF bookmarks、标题检测都是边界候选，必须对照实际起止页；避免目录页误判章节正文。DOCX/EPUB没有稳定印刷页码时使用章节/节标题、段落或定位锚点，不编造页码。不能无损拆分时保留原书及忠实章节摘取，并明确格式差异。

## 全书扫读

依次检查前言/适用对象、完整目录、每章正文结构与概念、核心图表、章末总结和习题、附录与术语。Outline 要从书中内容回答：全书在解决什么问题、各章分别贡献什么、章节如何关联、章节顺序和前置知识是什么。不推测作者未表达的意图，不添加外部应用。概要按章节写，不能将几章的细读当作整书覆盖。异常页与未读范围记录在 Studio.json 或验证记录，补齐之后再更新覆盖状态。

拆分 PDF helper 的 plan 示例：

```json
{
  "source": "Textbook.pdf",
  "segments": [
    {"id":"front","title":"Front matter","start":1,"end":3,"output":"_source/Front_Matter.pdf","printed_pages":"i-iii"},
    {"id":"1","title":"Foundations","start":4,"end":12,"output":"Chapter 01 - Foundations/Chapter_Source.pdf","printed_pages":"1-9"},
    {"id":"2","title":"Applications","start":13,"end":22,"output":"Chapter 02 - Applications/Chapter_Source.pdf","printed_pages":"10-19"}
  ]
}
```

source 相对 plan 文件所在目录解析，也可填写已授权读取的绝对源路径；plan 可放课程 `_studio/`。输出根目录必须通过 CLI 的 `--output-root` 单独传入已核实的课程目录，不从 plan 接受输出根。所有 segment output 相对此目录解析，不允许越界。所有物理页必须在 plan 中恰好覆盖一次；前后附属材料可放 `_source/`。工具不会猜测章节范围，不会修改源 PDF，不覆盖既有章节文件。通过 `python scripts/split_pdf.py --plan PLAN.json --output-root READING_FOLDER --check` 检查，再不带 `--check` 生成。缺少 pypdf 时说明所需能力并选择已安装等价工具；不要自动安装依赖。

Markdown 等文本拆分应保留原文标题层级和编码，按源行/节边界登记所有段落；可验证摘取拼接后与原文一致，或明确记录必要的包装差异。检查各段首次/末次定位、全部内容覆盖且无意外重复，以及相对链接是否仍可解析。源内容本身有跨章链接时调整副本链接或附原书定位，保留原件。

## 官方考纲研究

以书籍/课程名、科目代码、机构和目标考试期为检索锚点，优先官方 syllabus、learning outcomes、assessment regulations、sample/mock examination、marking guidance、examiner reports。区分出版日期、适用考试期、查阅日期；新版本不一定适用于用户的考试期。

记录每个官方文件：名称、机构、版本/有效期、直接URL、相关页/节、提取的要求。将学习成果映射到本教材章节，发现新版考纲与旧教材差异时列出“新增/删除/范围不同”，而非悄悄修改教材事实。

题型与权重只能由适用官方资料支持。样卷出现某种题型是观察，不代表所有考试都只有该题型；“核心复习点”可依据官方成果或概念依赖选定，但没有频率数据不能叫“常考/必考”。没找到官方材料时保留检索关键词、已检查官方位置和待核实项；不需要反复搜索同一失败入口。

## 章节精读与可追溯教学

为每小节制作知识清单，建议字段：`knowledgeId`、标准术语、解释、条件/边界、逻辑关系、来源、官方成果映射、教学优先级及理由、易混点、应用例子、检验方式。重要性标签至少区分：官方要求、概念基础、教学推荐；不要混成官方押题。

对每个关键概念，在书籍提供依据的范围内说明“是什么、为什么、何时使用、与相邻概念差别”。原书未说明的原因或适用条件不自行补写。辨析依据书中的定义、条件和例子，给出可追溯的共同点、区别和边界；反例仅用于演示这些既有规则，不引入新事实。

公式表收录书中给出的符号定义/单位、适用前提、输入来源、推导或理解要点、计算步骤、舍入/符号规则和误用情形。仅填写原书支持的字段，不为填满表格补充常识条件或舍入规则；演示可以包含必要算术步骤。教材没有公式时写明，不人为添加。自行构造的数值案例必须计算复核并标注 Original example。

术语表保留书中标准术语、缩写全称、解释和相近术语，不用外部定义替换书中定义。知识关联用有方向/含义且可在书中核对的关系（depends on / produces / evaluates / contrasts with），不能仅画无语义连线或自行扩展关系。

统一制作顺序：知识清单 → 覆盖矩阵 → 教学讲解 → 辅助案例 → 节内检验 → 章末练习。覆盖矩阵映射每个重要知识点到本次请求的 PPT/讲稿、概览图、导图节点、闪卡或试题；未请求模块标为 Not requested，计划中的模块标为 Planned，不能假称已完成。不要求每个低重要细节都出题，但请求的模块不能全部遗漏重要概念或辨析。材料引用写在脚注、来源字段或答案中；讲师口述用教学语言，避免逐页介绍“教材说了什么”。
