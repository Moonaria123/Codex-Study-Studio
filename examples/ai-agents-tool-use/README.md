# AI agent tool-use study sample

Open **[StudyHub.html](StudyHub.html)** in a modern browser to explore the mind map, flashcards and quiz. Double-click a map node, double-tap on a touchscreen or press Shift+Enter to read its detailed explanation and source index. Source links open the frozen upstream lesson when selected.

The hub works offline and saves learning records in the current browser. Export **Data & backup → complete JSON** before changing browsers or moving the HTML file, then import it into the same course.

The **Chapter 04 - Tool Use** folder contains the editable slides, PDF lesson, complete narrated video, subtitles, knowledge overview and practice answers. Read [SOURCE.md](SOURCE.md) for the source edition and attribution; Microsoft's MIT notice is included under `_source/`.

To rebuild the sample, use the complete [Codex Study Studio repository](https://github.com/Moonaria123/Codex-Study-Studio) and follow [_studio/BUILD.md](_studio/BUILD.md).
