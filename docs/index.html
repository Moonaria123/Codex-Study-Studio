05 / MAKE IT YOURS

Choose your way in.

English and Chinese packages are complete and independent. Install one or both. The bundled study-hub interface starts in English.

01

Ask Codex

Use $skill-installer to install the skill from
https://github.com/Moonaria123/Codex-Study-Studio/tree/main/skills/study-studio-en
02

Download a ZIP

Extract the skill folder into ~/.codex/skills/ or %USERPROFILE%\.codex\skills\. Keep the folder containing SKILL.md intact.

English package ↓Chinese package ↓
03

Clone & install

git clone https://github.com/Moonaria123/Codex-Study-Studio.git
cd Codex-Study-Studio
python scripts/install.py --language en
04

Bundled installer

python3 "$CODEX_HOME/skills/.system/skill-installer/scripts/install-skill-from-github.py"   --repo Moonaria123/Codex-Study-Studio   --path skills/study-studio-en

Set CODEX_HOME first, or use the default-home commands in the full guide.
